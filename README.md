# Moviesta Android

Android IPTV/VOD client built with Kotlin, Jetpack Compose and AndroidX Media3.

## Build APK on GitHub

1. Open **Actions** and select **Build Moviesta APK**.
2. Select **Run workflow** (or push to `main`).
3. When the run succeeds, open its **Artifacts** section and download `Moviesta-debug-apk`.

The workflow builds `app-debug.apk` using JDK 17 and Gradle 8.7.

## Features

- Xtream Codes login
- Movies, series, and live TV categories
- Search and favorites
- Series episode selection
- Media3/ExoPlayer playback

Use only IPTV services and streams that you are authorized to access.
